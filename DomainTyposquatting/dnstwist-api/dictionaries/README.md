# Dictionaries

Download the dictionaries folder from the official dnstwist repo:
https://github.com/elceef/dnstwist/tree/master/dictionaries

Place these files here:
- common_tlds.dict (for tld-swap fuzzer)
- english.dict (for dictionary fuzzer)

Or download directly:
```bash
curl -O https://raw.githubusercontent.com/elceef/dnstwist/master/dictionaries/common_tlds.dict
curl -O https://raw.githubusercontent.com/elceef/dnstwist/master/dictionaries/english.dict
```
